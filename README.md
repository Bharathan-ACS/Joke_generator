# 😂 Joke Generator Web App

A simple and interactive Joke Generator web application built using Django. The app fetches random jokes from an external API and displays them dynamically to the user.

## 🚀 Features
- Generate random jokes with a single click
- Fetch jokes from a public API
- Clean and responsive UI using Bootstrap
- Server-side rendering using Django templates

## 🛠️ Tech Stack
- Frontend: HTML, CSS, Bootstrap
- Backend: Django (Python)
- API Integration: Requests library

## 🔗 How It Works
1. User clicks "Generate Joke"
2. Django view sends request to a joke API
3. API returns joke in JSON format
4. Django processes data and renders it in UI

## 📦 Installation

1. Clone the repository
git clone <your-repo-link>
cd joke-generator

2. Create virtual environment
python -m venv venv

3. Activate environment
venv\Scripts\activate (Windows)

4. Install dependencies
pip install django requests

5. Run server
python manage.py runserver

6. Open in browser
http://127.0.0.1:8000/
